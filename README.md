# 建项目监控

`建项目监控` 是 Windows 本地桌面程序，用于监控已授权千川账户中的项目单元数。当同一项目组的最高编号项目达到阈值（默认 88）时，程序创建名称尾缀加一的新项目，并复制该源项目最新的单元。

当前发布版本：`2.0.6`。安装包与校验值见 [GitHub Releases](../../releases)。面向维护者的完整交接信息见 [HANDOFF.md](HANDOFF.md)。

新 Windows 接手、版本构建、GitHub Release、手工升级和网站边界见 [docs/RELEASE-GUIDE.md](docs/RELEASE-GUIDE.md)。

## 安装与首次启动

1. 从与版本号相符的 GitHub Release 下载 `建项目监控-2.0.6.zip`。
2. 解压整个压缩包到一个本地目录；不要只复制 `建项目监控.exe`。目录必须保留 `建项目监控\\_internal\\` 和 `scripts\\`。
3. 双击 `建项目监控\\建项目监控.exe`。Windows SmartScreen 可能因该版本未做商业代码签名而提示风险；不要关闭系统安全功能，请按组织的可信软件流程处理。
4. 在 **授权配置** 中输入你本人授权的 `APP_ID`、`Secret` 和包含 `auth_code` 的完整回调地址，点击 **保存并导入授权**。
5. 在 **账户与项目** 中按需填写账户 ID（每行一个）并保存；也可留空，程序会使用本次授权返回的账户列表。
6. 回到 **运行总览** 或 **监控控制**，点击 **启动后台监控**。

程序只在本机保存配置、令牌、扫描结果和日志。不要把旧电脑的授权、Token、Secret、账户 ID、`config/`、`data/` 或 `logs/` 复制到新电脑，更不要上传到 GitHub。

## 主要操作

### 授权配置

- `APP_ID` 必须为至少 10 位数字；`Secret` 至少 16 个字符；回调地址必须是包含 `auth_code` 参数的完整 HTTP(S) URL。
- 点击 **保存并导入授权** 会向千川接口换取并保存本机 Token。请只使用自己有权使用的应用和回调地址。
- 更换接口或重新授权时，在同一页面重新填写并导入；不要手工编辑 `data/tokens.json`。

### 账户与项目

- 填入账户 ID 后，该列表是严格的扫描白名单；程序不会再以这些 ID 发现其他子账户。
- 清空并保存后，程序改用本次授权返回的账户列表。
- 页面显示的是最近一次扫描中每个账户的前 10 个项目；没有扫描结果时先启动监控并等待一次扫描完成。

### 监控控制

- 常规扫描间隔为 10 分钟，界面状态约每 10 秒刷新一次。
- “立即扫描一次”可能创建项目和单元，只有确认当前授权、账户列表与业务规则无误后才可使用。
- “安全停止”会在当前 API 扫描结束后停止后台进程；关闭界面本身不会停止已启动的后台监控。
- 可在界面中安装或取消开机自启。程序优先创建当前 Windows 用户的计划任务；无权限时会改用启动文件夹。

## 规则与限制

- 项目名以最后的 `_数字` 作为序号；每个同名项目组只检查序号最高的项目。达到 88 个单元时，目标名称为该最高序号加一。
- 新项目会复制源项目的最新单元。创建或复制失败会写入本机失败队列，默认 3 分钟后重试。
- 千川接口返回“已创建 30 个项目”之类的项目数上限时，程序不会自动删除、绕过或清理项目；需要由账户管理员处理。
- 程序会保留本机日志约 72 小时。日志和失败队列可能含业务信息，不得上传或提交。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示尚未导入授权 | 在 **授权配置** 中填写本人信息并完成“保存并导入授权”；不要复制其他电脑的 Token。 |
| 回调地址校验失败 | 粘贴包含 `auth_code` 的完整回调 URL，而不是只粘贴授权码。 |
| 授权成功但账户列表有警告 | 检查手动账户 ID 是否属于当前授权；删除无权限的 ID，或清空列表后重新导入授权。 |
| 没有扫描结果 | 确认后台监控已启动，等待首轮扫描，并在 **运行日志** 查看 `project_monitor.log`。 |
| 创建失败持续重试 | 在日志中确认接口返回原因；项目数上限、权限不足和接口参数错误需要人工处理。不要手工改失败队列或 Token 文件。 |
| Windows 阻止打开程序 | 本版未使用商业代码签名。不要关闭防护；通过组织的软件分发/签名流程验证来源。 |

## 从源码开发

要求：Windows、Python 3.13、PowerShell 和 Git。程序运行时只使用 Python 标准库；开发和打包依赖见 `requirements-dev.txt`。

```powershell
py -3.13 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install -r requirements-dev.txt
.\\.venv\\Scripts\\python.exe -m pytest -q
.\\.venv\\Scripts\\python.exe app\\manager_gui.py
```

构建本地候选包：

```powershell
$env:PATH = "$PWD\\.venv\\Scripts;$env:PATH"
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\\build_desktop_release.ps1
```

输出为 `release\\建项目监控-<版本号>`。构建脚本只复制程序、依赖、脚本、使用说明和版本文件；不要把本机私密目录加入安装包。发布、升级和维护细节见 [HANDOFF.md](HANDOFF.md)。

## 私密文件边界

下列项目均为本机私密数据，已由 `.gitignore` 排除，禁止读取、提交、打包、上传或用新版本覆盖：

- `config/`
- `data/`，包括 `tokens.json`、失败队列和扫描快照
- `logs/`
- 根目录和 `release_template/` 下的 `千川接口.txt`、`账户ID.txt`、`项目名称.txt`
