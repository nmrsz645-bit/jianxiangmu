建项目监控软件使用说明（v2.0.6）

一、安装
1. 解压整个“建项目监控-2.0.6”目录；不要只复制 EXE。
2. 确认“建项目监控\\_internal”和“scripts”仍在原目录中。
3. 双击“建项目监控\\建项目监控.exe”。本版本未使用商业代码签名，如 Windows 提示风险，请按可信软件流程核验来源，不要关闭系统安全功能。

二、首次配置
1. 打开“授权配置”。
2. 由你本人填写已获授权的 APP_ID、Secret 和包含 auth_code 的完整回调地址。
3. 点击“保存并导入授权”，等待授权结果成功。
4. 打开“账户与项目”：需要限定账户时，每行填写一个账户 ID 并保存；留空则使用本次授权返回的账户列表。
5. 返回“运行总览”或“监控控制”，点击“启动后台监控”。

三、日常使用
- 常规扫描间隔为 10 分钟，状态面板约每 10 秒刷新。
- 项目组中编号最高的项目达到 88 个单元时，程序会创建下一个编号项目并复制最新单元。
- “立即扫描一次”会按当前规则执行创建操作，只在确认配置和账户范围正确后使用。
- 关闭界面不会停止后台监控；要停止请点击“安全停止”，它会在当前扫描结束后退出。
- 可在“监控控制”安装或取消开机自启。

四、问题处理
- 提示未授权：在“授权配置”重新填写并导入；不要手动改 token 文件。
- 回调地址无效：必须粘贴包含 auth_code 的完整 URL，不能只填授权码。
- 授权后账户有警告：检查手动账户 ID 是否具有当前授权；删除无权限 ID，或清空列表后重新授权。
- 无扫描结果或创建失败：打开“运行日志”查看 project_monitor.log。接口项目数达到上限时程序不会自动删除旧项目，需要账户管理员处理。

五、安全边界
config/、data/、logs/、千川接口.txt、账户ID.txt 和项目名称.txt 都是本机私密数据。请勿复制旧电脑的这些文件，请勿上传、提交或把它们打进安装包。

完整开发、发布和交接说明请见源码仓库的 README.md 与 HANDOFF.md。
